# Los Santos +

## Description du projet
**Los Santos +** est un serveur de jeu multijoueur basé sur le mod [San Andreas Multiplayer (SA-MP)](https://www.sa-mp.mp/) pour le jeu Grand Theft Auto: San Andreas. Le serveur offre une expérience de jeu de rôle immersive dans l'univers de San Andreas, où les joueurs peuvent interagir, accomplir des missions, rejoindre des factions, et bien plus encore.
